Rewrite the README's Claude Code section around the four plugin tiers, and register `cornerstone-designer` in the `cru` marketplace.

The section still advertised "a plugin with two commands". One of those commands, `/design-review`, has been deprecated since #75, and there are now four plugins: `cornerstone` (everyone), `cornerstone-designer` (designers), `cornerstone-dev` (contributors), and `cornerstone-skills`, which is only ever installed as a dependency of the contributor tier. Each tier is described by audience and by what installing it pulls in, with the manifests at `plugins/*/.claude-plugin/plugin.json` named as the source of truth — the tiers being installable plugins instead of a list to follow by hand is the decision in #67, and a README table that outranked them would undo it.

Every dependency now carries its reason, and the two non-base tiers need `figma` for different reasons — the designer tier because `see-it-in-figma` builds in Figma through `use_figma`, the contributor tier because `/pull-tokens` and Joseph's design-to-code path do. A designer never runs `/pull-tokens`, so it isn't why their tier carries it. `cornerstone-skills` is a dependency because the contributor personas name those skills in their own instructions, and `cornerstone` because it carries the front door that routes to a persona at all. The contributor prerequisites no longer walk through installing the Figma plugin by hand — `cornerstone-dev`'s `dependencies` array does that — and keep only the steps that are still a human's: authenticating and restarting.

Adds the install-time naming note #74 asked for, describing the mechanism #74 actually recorded. Plugin agents are not namespaced, and Claude Code resolves agents by walking its sources in order — built-in, plugin, user settings, project settings — into one map keyed on the agent's name, so a local `sarah` is applied after the plugin's and evicts it. Only one loads, and it is the consumer's. The shadowing is silent because the duplicate-name warning only compares agents from the same source, so a cross-source collision is never reported. The note tells installers to grep their own agent frontmatter for the five persona names before installing, and that renaming theirs is the whole remedy — there is no namespaced name to fall back on.
