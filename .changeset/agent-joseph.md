Add Joseph, the component-authoring persona, to the `cornerstone-dev` plugin — built per #63 (as amended by #66) and #74, with an Opus model floor.

Joseph owns the full lifecycle of every `cs-*` component in `@cruglobal/cornerstone-components`, against the API contract on draft PR #59 — which the file notes is not yet on `main`. He never writes `tokens/*.json`: primitives are requested from Sarah, and a fix touching `_ref`/`_sys` goes through her CODEOWNERS gate without inheriting an exemption from it. He never writes a `.stories.js` file, Storybook config, or its CI checks — #66 moved all of that to Anna, so his one-time workspace bootstrap is npm workspace registration and build tooling only, sequenced after Sarah/Esther/Anna exist and gated on human sign-off. Esther is a blocking review on every PR he opens. Bespoke one-off UI is refused and redirected to Content Platform Engineering, and external design-system inspiration triggers a grilling session before adoption.

Where the spec summarised a mechanism, the file describes what the repo actually does. The generated CSS contains no `var()` references at all — `build.mjs` never sets `outputReferences`, so the `_ref` → `_sys` → `_cmp` chain has no runtime existence and the variable names a component reads are the consumer's entire override surface. `--cmp-*` and `--sys-*` are emitted only inside `[data-brand][data-theme]` selectors, so an unthemed host resolves nothing. `libraries/mui` and `libraries/daisyui.css` are hand-maintained snapshots of resolved values rather than token consumers, and have already drifted from each other on border radius, so neither is a precedent for how components consume tokens — and shipping raw TypeScript the way `./mui` does is impossible for components, since `importmap-rails` and a WordPress module enqueue load files directly in a browser. Motion is a pipeline change rather than a token addition: no duration branch exists in `value/number/unit`, and `_ref` carries only `color`, `number` and `string` types. The bootstrap is framed as a release-pipeline edit, since a second workspace package enters the changesets graph and arms a publish, `npm install lit` at the root would break the zero-dependency guarantee that keeps token-only consumers clean, and CI runs no lint or test job today.

Two conflicts are recorded rather than resolved: App shell ranks third in UIUX-115's Wave 1 while sitting on the far side of Joseph's refusal to compose page-level patterns, and UIUX-115's demand ordering disagrees with the conventions doc's settled Alert/Toast API about what is actually buildable first.
