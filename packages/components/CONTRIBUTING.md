# Contributing to Cornerstone Components

Cornerstone Components is the custom-element library of the Cornerstone design system, maintained by the
Cru design system team.

## Issues

Bug reports and questions are welcome from anyone. Open an issue at
[github.com/CruGlobal/cornerstone-components/issues](https://github.com/CruGlobal/cornerstone-components/issues).

A useful report says which component, which browser, and what you expected instead. A reduced test case
is worth more than a description.

## Pull requests

Pull requests come from the Cru design system team. The repository is public and MIT-licensed, so anyone
is free to fork it and build on it, but this project does not take outside contributions — there is no
capacity to review and support them across the component library.

If you have found a bug and know the fix, say so in the issue. That is more useful than a patch nobody
is able to review.
