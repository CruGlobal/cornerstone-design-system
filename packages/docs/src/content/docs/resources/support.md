<p>Cornerstone Components is built for Cru and FamilyLife product teams, and the package is published privately — so support is internal rather than open-source. Bugs and requests go to the repository. If you have not used the library before, start with <a href="/">Where to start</a> on the home page.</p>

<cs-divider></cs-divider>

  <div class="cs-stack cs-gap-s">
    <h2 class="anchor-heading"><cs-icon name="github" library="brands"></cs-icon>GitHub</h2>
    <span class="cs-heading-m">Bugs and requests</span>
    <p class="cs-caption-l">Open an issue so it can be triaged and tracked. One issue per problem, and say which version you are on.</p>
  </div>
  <ul>
    <li>For a bug, give the steps that reproduce it and what you expected instead.</li>
    <li>For a component that behaves differently across browsers, say which ones you checked.</li>
    <li>For a new component or a new option on an existing one, describe the case it has to serve rather than the API you would like.</li>
  </ul>
